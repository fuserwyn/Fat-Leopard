## выполнение

Сделано для задачи #109 — обсуждение предложений Лео при создании задачи.

**Бэкенд** (`miniapp_admin_leo_task.go`, `admin.go`):
- Эндпоинт `leo-propose` принимает `feedback` и `previous` (черновик для обсуждения).
- В режиме обсуждения Лео отвечает с пояснением и 1–3 вариантами формулировки (`variants`).

**Фронтенд** (`TrackerScreen.tsx`, `trackerApi.ts`):
- После предложения Лео — поле «Обсудить с Лео» для уточнения деталей.
- Если Лео вернул несколько вариантов — выбор карточками (как в спринтах).
- Кнопка «Зафиксировать на доске» ставит выбранный вариант на доску.
- «Не то, давай другую» по-прежнему просит новую идею с нуля.

Локальный коммит не создан: в окружении не настроен git user (менять config нельзя). Изменения лежат в рабочей директории, трекер может закоммитить при пуше.
