# Задача трекера #127

Задача #127.

На экране загрузки фото при внесении тренировки сделать так, чтобы обрезка фото вызывалась по отдельному клику на функцию обрезать фото рядом с кнопкой готово, а не включалась автоматически при загрузке фото

## выполнение

Сделано для задачи #127.

**Изменения:**
- Вернул экран предпросмотра `PhotoConfirm` — после выбора фото (галерея, камера, буфер) показывается превью, а не кроппер.
- На экране предпросмотра две основные кнопки рядом: **«Готово»** (принять фото как есть, с подготовкой через `prepareWorkoutPhoto`) и **«Обрезать фото»** (открывает `PhotoCropper` только по клику).
- Есть также **«Загрузить другое фото»** и **«Отмена»**.
- При отмене обрезки пользователь возвращается на экран предпросмотра.
- Повторная обрезка уже прикреплённого фото по иконке в форме по-прежнему открывает кроппер напрямую.

**Файлы:** `PhotoConfirm.tsx`, `PhotoConfirm.css`, `NewWorkoutScreen.tsx`.

Сборка miniapp проходит успешно. Локальный коммит не создан — в окружении не настроен git user; изменения в рабочей копии на ветке `tracker/127-808`, готовы к пушу трекером.
