## выполнение

Сделано для задачи #124:

**Убран принудительный шаг обрезки** — после выбора фото из галереи, камеры или буфера снова открывается экран подтверждения (`PhotoConfirm`), а не сразу `PhotoCropper`.

**Экран подтверждения** — фото можно принять кнопкой «Готово» без обрезки (сжатие через `prepareWorkoutPhoto`). Обрезка только по клику на иконку кропа в шапке (стандартная SVG-иконка, не текст).

**В форме отчёта** — у уже прикреплённого фото кнопка «Обрезать» заменена на такую же иконку.

Изменённые файлы: `PhotoConfirm.tsx`, `PhotoConfirm.css`, `NewWorkoutScreen.tsx`, `NewWorkoutScreen.css`.

Локальный коммит не создан — в окружении нет git user identity; трекер может закоммитить при пуше.
