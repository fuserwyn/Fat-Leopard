# Задача трекера #81

Задача #81.

Необходимо переделать раздел “Поддержать проект” в профиле пользователя.

Убать из выпадающего меню. Оставить кнопку “Поддержать проект”. При нажатии на кнопку открывается модальное окно с вариантами оплаты. Дальше оплата без изменений.

Над кнопкой “Поддержать проект” оставить текст “Донат по желанию: он не отменяет вылет за неактивность, но помогает Лео и проекту жить. Ты уже поддержал N раз. Спасибо!”, где N - это каунтер количества донатов пользователя.
Размер и тип шрифта аналогично другим аннотациям.
