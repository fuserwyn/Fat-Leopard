# Задача трекера #94

Задача #94.

Добавить на главную страницу прогресс-бар, отображающий суммарное количество выполненных тренировок стаи за неделю. Бар заполняется по мере приближения к цели (например, 100 тренировок). Цель сбрасывается каждое воскресенье, а при её достижении стая получает общий бонус (например, эксклюзивную тему в чате на день).

## выполнение

Сделано для задачи #94.

**Бэкенд**
- Подсчёт тренировок стаи за неделю (воскресенье–сегодня, МСК) через `CountPackTrainingSessionsInDateRange`
- Миграция `pack_weekly_goal_bonus`: при достижении 100 тренировок выдаётся бонус на 24 часа
- API `/api/miniapp/profile/load` и `/save` отдают `pack_workouts_week`, `pack_workouts_goal`, `pack_goal_reached`, `pack_bonus_theme_active`
- Новая тема `pack` («Стая») доступна только при активном бонусе
- Проверка цели срабатывает после каждой сохранённой тренировки

**Фронтенд**
- Прогресс-бар «Неделя стаи» на главной (`FeedScreen`) под стриком: счётчик X/100 и заполнение бара
- Состояние подтягивается из профиля в `App.tsx`, обновляется после тренировки
- Тема «Стая» в настройках профиля при активном бонусе
- Тесты: `packWeeklyGoal`, `theme`, `FeedScreen`, Go `week_utils` и `miniapp_theme`

Локальный коммит не создан: в окружении не настроен git user (менять config по правилам нельзя). Изменения в рабочей копии на ветке `tracker/94-732` — трекер подхватит их при push.
