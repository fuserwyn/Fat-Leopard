# Задача трекера #121

Задача #121.

При добавлении фото во время записи тренировки инструмент обрезки фото не должен включаться сразу, а должен быть предложен на экране подтверждения фото рядом с кнопкой готово, пользователь может выбрать кроп при необходимости. Дополнительно рядом с кнопкой кропа добавить кнопку загрузить другое фото.

## выполнение

Изменён поток добавления фото при записи тренировки.

**Что сделано:**

1. **`PhotoConfirm`** — новый экран подтверждения с превью фото и кнопками:
   - **Готово** — принять фото без обрезки (с ужатием до JPEG, как раньше в кроппере)
   - **Обрезать** — открыть `PhotoCropper` по желанию
   - **Загрузить другое фото** — выбрать другой снимок

2. **`NewWorkoutScreen`** — при выборе из галереи, камеры или вставке из буфера открывается экран подтверждения, а не кроппер сразу. Кнопка «Обрезать» у уже прикреплённого фото по-прежнему открывает кроппер напрямую.

3. **`prepareWorkoutPhoto.ts`** — подготовка фото без обрезки (downscale + JPEG).

Сборка `npm run build` проходит успешно. Локальный коммит не создан — в окружении не настроен git user; изменения готовы к пушу трекером.
