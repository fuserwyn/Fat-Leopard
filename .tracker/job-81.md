# Задача трекера #77

Задача #77.

Когда я открываю экран отметки выполненной тренировки,
я хочу получать персонализированный список тренировок, где в начале отображаются наиболее вероятные варианты на основе моей истории, целей и текущего контекста,
чтобы быстро найти нужную тренировку и продолжить пользоваться приложением без лишнего поиска

## выполнение

Сделано: персонализированный порядок типов тренировок на экране отметки.

**Бэкенд**
- Алгоритм ранжирования в `workout_suggest.go`: частота и свежесть истории, совпадение дня недели и времени с прошлыми отчётами, контекст (утро/вечер, перерыв с упором на восстановление).
- Запрос последних сессий из `training_sessions`.
- Поле `suggested_workout_types` в `/api/miniapp/profile/load`.

**Фронтенд**
- `workoutSuggest.ts` — переупорядочивание списка по подсказкам сервера.
- `NewWorkoutScreen` показывает типы в персональном порядке.
- `App.tsx` загружает подсказки из профиля и обновляет их при открытии формы «+».

**Тесты** — Go (`workout_suggest_test.go`) и Vitest (`workoutSuggest.test.ts`).

Локальный коммит не создан: в окружении не настроен git user identity. Изменения в рабочей директории на ветке `tracker/77-613`.
