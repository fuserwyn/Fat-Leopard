# Задача трекера #107

Задача #107.

В админке не брать задачу если есть задача в работе 
Новая задача тогда должна быть в статусе ожидает

## выполнение

Сделано для задачи #107.

**Проблема:** при создании задачи в админке, пока другая уже в конвейере, новая могла уходить в «В работе» (или висеть там с шагом «ждёт очередь») вместо «Ожидает».

**Исправления:**

1. **`localTrackerCreate`** — автозапуск («сейчас») только если конвейер свободен.
2. **`approveTrackerTask`** — после двух аппрувов при занятом конвейере карточка остаётся в «Ожидает» с шагом «Два аппрува — ждёт очередь».
3. **`localTrackerRestart` / `localTrackerReschedule`** — перезапуск не переводит в «В работе», пока занята другая задача.
4. **`dispatchTrackerAgent`** — при занятом конвейере карточка возвращается в «Ожидает» (функция `trackerKeepInWaitingQueue`).

**Тесты** добавлены в `tracker_queue_test.go`.

Локальный коммит не создан — в окружении не настроен git user. Изменения в рабочей копии на ветке `tracker/107-709`, трекер может закоммитить и запушить сам.
