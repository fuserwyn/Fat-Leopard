# Задача трекера #155

Задача #155.

Гостевой просмотр. По ссылке из чужой карточки человек видит ленту стаи без вступления: несколько постов и кнопку «Вступить». Сейчас снаружи продукт не видно совсем.

## выполнение

Гостевой просмотр готов: человек, который ещё не в стае, открывает мини-апп и видит последние тренировки стаи и кнопку «Вступить». Раньше такой человек получал приложение, где ничего не загружалось. Все проверки выкатки по ms_leo и miniapp прошли. Вживую в Telegram экран не смотрел, только тестами.

**Как человек попадает в ленту.** По ссылке из чужой карточки он приходит к боту и видит экран оплаты. Под способами оплаты теперь есть кнопка «👀 Посмотреть ленту стаи», она открывает мини-апп. Кнопка появляется, только если в настройках задан адрес мини-аппа (`MINIAPP_WEB_APP_URL`).

**Что видит гость.**
- Заголовок «Так стая тренируется каждый день» и до 5 последних тренировок: имя, текст отчёта, фото, стрик, время.
- Наружу не уходят id авторов, аватарки, комментарии, реакции и системные карточки. Скрытые посты гостю тоже не показываются.
- Карточки только для чтения.
- Кнопка «Вступить» прибита к низу экрана и открывает чат с ботом по ссылке `?start=src-guest_feed`. Там обычная оплата или бесплатный вход, а в аналитике такой визит запишется с источником `guest_feed`.

**Когда показывается гостевой экран.** Только если сервер прямо ответил, что человека нет в стае. Выбывшие за неактивность по-прежнему видят экран блокировки. Если сервер не ответил, приложение открывается как раньше. Если стая не настроена, гостевой экран не показывается.

**Решение на ваш выбор:** фото тренировок участников видны людям вне стаи. Если это нежелательно, их можно убрать из ответа одной строкой.

**Сервер (ms_leo):**
- `internal/bot/miniapp_guest_feed.go` (новый) — сборка гостевой ленты. Нового SQL нет, используется существующий запрос ленты.
- `internal/miniappapi/server.go`, `server_feed.go` — новый маршрут `POST /api/miniapp/feed/guest`. Он требует подпись Telegram, но не членство в стае.
- `internal/bot/paywall.go` — кнопка «Посмотреть ленту стаи».
- Тесты: `internal/bot/miniapp_guest_feed_test.go` и сквозной `internal/miniappapi/guest_feed_integration_test.go` на настоящей базе. Сквозной проверяет, что обычная лента гостю закрыта, а гостевая отдаёт 5 свежих постов без лишних полей.
