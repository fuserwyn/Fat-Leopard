# Задача трекера #118

Задача #118.

Если юзер пишет коммент под постом Лео, то Лео должен отвечать ему, это как реплай механизм должно работать

## выполнение

Сделано для задачи #118:

**Backend (`ms_leo`)**
- Добавлена функция `packFeedPostIsLeo` — определяет посты Лео (`daily_wisdom`, `admin_post`/`admin_poll` с автором «Лео»).
- Расширен триггер `shouldLeoReplyInFeedThread`: Лео отвечает не только на @leo и reply на его сообщение, но и на любой комментарий под его постом.
- В `packFeedSupportsThread` добавлен `daily_wisdom` — комментарии к мудрости дня теперь принимаются API.
- В `LeoReplyInFeedThread` добавлен промпт для случая «комментарий под постом Лео».
- Добавлен `GetUserMessageUsernameByIDForChat` для определения автора карточки.
- Обновлены тесты.

**Frontend (`miniapp`)**
- В `FeedScreen.tsx` для `daily_wisdom` включены треды — можно комментировать мудрость дня.

Поведение: пользователь оставляет комментарий под постом Лео (мудрость дня или объявление) → Лео отвечает через существующий механизм `LeoReplyInFeedThread` (AI, DM, бейдж). Под чужими отчётами о тренировке без @leo/reply поведение не менялось.

Локальный коммит не создан — в окружении не настроен git user. Изменения в 5 файлах готовы к пушу трекером.
