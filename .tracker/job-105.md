# Задача трекера #101

Задача #101.

Если админ или админы не апррувят отклоняют аппрувы ( то есть не реагируют на уведомление) задачи в течении часа, то уведомление тому, кто не аппрувнул должно прийти повторно

## выполнение

Сделано повторное уведомление админам об аппруве через час без ответа.

**Что изменилось:**

1. **БД** — в `pack_tracker_tasks` добавлены поля `approval_notified_at` и `approval_reminder_sent_at` для отслеживания первичной рассылки и повторного напоминания.

2. **Отправка уведомлений** (`tracker_approval.go`) — при первом уведомлении фиксируется время в БД; при повторном напоминании сообщение уходит только админам, которые ещё не аппрувнули, с префиксом «⏰ Напоминание:».

3. **Планировщик** (`tracker_approval_reminder.go`) — каждые 5 минут проверяет задачи на аппруве, где прошёл час с первого уведомления и повтор ещё не отправляли; запущен в `bot.go`.

4. **Тесты** — проверки фильтрации админов, текста напоминания и логики «пора напоминать через час».

Локальный коммит не создан: в окружении не настроен git user (конфиг не меняю). Изменения в рабочей копии на ветке `tracker/101-692`.
