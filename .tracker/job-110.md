# Задача трекера #106

Задача #106.

В админке показывать всех участников за всю историю стаи, вывести отдельно каунтер активных участников и кикнутых и возможность фильтровать активные/кикнутые

## выполнение

Сделано для задачи #106.

**Бэкенд**
- В `admin_moderation.go` добавлены счётчики `total/active/kicked`, фильтр `all/active/kicked` для списка и поиска.
- API `/api/miniapp/admin/users` принимает `filter`, отдаёт `total`, `users_active`, `users_kicked`.
- В overview добавлены поля `users_active` и `users_kicked`.
- В Telegram-админке в подписи списка показываются счётчики активных и кикнутых.

**Мини-апп (AdminScreen)**
- На главной — отдельные счётчики «активных» и «кикнутых» вместо одного «в стае».
- На странице «Участники» — сводка за всю историю, вкладки «Все / Активные / Кикнутые» с числами, пагинация (по 20), поиск с учётом фильтра.
- Список обновляется после кика/восстановления.

Локальный коммит не создан — в окружении не настроен git user (конфиг не менял). Изменения в рабочей копии, трекер может закоммитить и запушить сам.
